## Contributions are welcome but please read the following

The website code is currently closed source but could parts could be made public in the future if enough people request it.

If you have any feature requests, bug reports or gym submissions, please use the `Issues` or `Discussions` sections of the repository.
If you're interested in helping with the code, please reach out.

## Licensing of contributions

By contributing to this repository, whether through a pull request, an issue or a discussion, you
agree that your contribution is provided under [CC BY 4.0](./LICENSE), the same licence as the rest
of the repository.

You keep the copyright in what you write. This just gives everyone, including the
[Gym Directory UK](https://gymdirectory.co.uk) website itself, the right to use, adapt and publish
it. The website is a commercial project, so without this the data set could be published here and
still not be usable by the site it exists to serve.

Only contribute material you have the right to license. Copying descriptions from a manufacturer's
website, another directory or a wiki is not something we can accept, however useful it looks.
Facts, such as what an exercise targets or where a gym is, are fine; someone else's wording is not.
